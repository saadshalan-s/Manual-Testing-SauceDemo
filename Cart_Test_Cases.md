# Cart Test Cases

| ID | Test Case | Expected Result |
|----|-----------|-----------------|
| TC-016 | Open Shopping Cart | Shopping Cart page should open successfully |
| TC-017 | Verify added products are displayed | Added products should appear in the cart |
| TC-018 | Remove a product from the cart | Product should be removed successfully |
| TC-019 | Continue Shopping | User should return to the Products page |
| TC-020 | Proceed to Checkout | Checkout page should open successfully |
| TC-021 | Verify cart badge after removing a product | Cart badge should update correctly |
| TC-022 | Verify empty cart behavior | Empty cart message or empty list should be displayed |
| TC-023 | Verify product quantity | Product quantity should be displayed correctly |
| TC-024 | Verify multiple products remain in cart | All selected products should remain in the cart |
| TC-025 | Verify cart information accuracy | Product names, prices, and quantities should be correct |
